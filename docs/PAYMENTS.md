# Payments

Implemented: configurable admin-created QAR/USD prices, company-owner checkout, immutable transaction price/currency snapshot, an internal sandbox provider, signed timestamped test events, exact amount/currency checks, unique event IDs/replay idempotency, test entitlements, test receipts, internal refund service and billing history. Card inputs do not exist. Browser redirects never mark a transaction paid. Test entitlements cannot satisfy live publication controls.

Sandbox events POST JSON to `/integrations/sandbox/webhook/` with `X-Timestamp` and `X-Signature`. Signature is HMAC-SHA256 over `<timestamp>.<raw body>` using SANDBOX_WEBHOOK_SECRET (development-only fallback exists). Accepted timestamp skew: 300 seconds. Body contains exactly event_id, reference, amount_minor integer, currency and status paid/failed. Terminal transactions cannot be rewritten; identical event retries are idempotent and conflicting reuse is rejected. Interactive simulation is development-only. This protocol belongs solely to the internal sandbox; it is not QNB's protocol.

The provider interface includes create/verify/refund/webhook validation/reconciliation/settlement methods. Live Qatar acquiring is **not implemented**. QNB describes a local merchant gateway covering cards and QPay: https://qnb.com/sites/qnb/qnbglobal/en/ennews041023news . QCB payment regulation: https://www.qcb.gov.qa/Services/Financial%20Technology/PSR%20Final%20-%20English.pdf . Recheck immediately before implementation and obtain actual merchant API specifications, approved sandbox credentials and signed agreement. Do not invent integration endpoints or assume Stripe availability.

Owner approval is required for merchant agreements, credentials and live activation. Acquirer confirms onboarding, banking/settlement, currencies, international card acceptance, 3DS, dispute/refund fees, webhook authentication and reconciliation. Qualified accountant confirms legal entity/tax invoice fields and tax rules. Test receipts are prominently marked not tax invoices. No live payments or settlement reconciliation are claimed.
