# Candidate guide

The GitHub project website is informational; real applications are not open there. In a configured application environment, browse published vacancies and apply as a guest or verified registered candidate. Upload PDF/DOCX/TXT up to 5 MB, provide relevant information and read/accept the vacancy processing notice. Do not upload identity/banking/medical/family documents by default.

Every saved application receives a reference. Guests receive a one-use email link opening a two-hour private session; recover links at `/applications/recover/`. A matching verified candidate account can claim an application when opening its guest link. Never share a private link or paste CVs into public GitHub issues.

The candidate workspace shows own applications and stages. Recruiter notes and internal reasons remain confidential. Withdraw with a reason. Interview invitations show purpose, retention context and what is collected; consent before reserving a slot, save text responses and submit when ready. Current assessment is human, not automated AI.

Maintain a professional profile and candidate-provided URLs (not scraped). Privacy centre accepts access, correction, export and deletion requests. Self-export at `/portal/privacy/export/` returns own account/application fields and responses. Actual deletion requests require review against legal obligations; the interface does not promise immediate destruction of legally held data.
