# Architecture and implementation boundary

Read BLUEPRINT.md for the complete target design and ERD. The repository currently contains a Django modular monolith. Modules: `views/security` accounts and access; `recruitment/documents` vacancies and private applications; `matching/parser` conservative evidence baseline; `interviews` text workflow; `payments` internal sandbox; `operations/privacy` administration, reports and retention.

The application uses database sessions and a custom UUID user from the first migration. Active memberships scope recruiter reads and mutations through the vacancy's company. Admin is a distinct role and every admin view checks verified email and session-bound MFA. Django's default admin site is not mounted. Candidate and guest projections exclude internal notes and recruiter rationales.

Public GitHub Pages output is generated by an explicit allowlist of templates and text. It does not query/export applicants, render account forms, include secrets or pretend to provide live recruitment services. It is a project introduction; authenticated application deployment is separate.

Production intent is PostgreSQL + private encrypted object storage + web and background workers. Local SQLite and local private file storage are development conveniences. Web processes do not parse CVs on page loads. A task lease and retry schedule preserve pending documents across failures. Extraction is a resource-limited subprocess without inherited application secrets; scanning failure blocks extraction and downloading. Real scanner deployment and network-level worker isolation still require verification.

Important limitations: the matching implementation is a deterministic evidence baseline, not hybrid semantic AI; text interview grading is human; live acquiring is absent pending merchant specifications; advanced time-to-hire reporting, immutable external audit, complete translation, broader admin controls and independent penetration/restore review are not complete. These must not be represented as shipped production features.
