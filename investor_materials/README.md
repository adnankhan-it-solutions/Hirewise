# Hirewise investor materials

`Hirewise_Investor_Deck.pptx` is the editable investor presentation. Rebuild it with:

```sh
.venv/bin/python investor_materials/build_deck.py
```

The deck distinguishes verified public context, implemented product status, and management assumptions. Replace the founder/team slide, funding ask, pricing and financial scenarios with owner-approved data before circulation.

`Hirewise_Product_Requirements_Document.docx` is the editable, two-page product requirements document. Rebuild it with:

```sh
.venv/bin/python investor_materials/build_prd.py
```

The PRD records the product vision, users, MVP requirements, workflows, privacy controls, release scope, and acceptance gates. Review the marked management assumptions before treating it as an approved product baseline.
